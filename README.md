# 👁 iSeeAll — Telegram Business Bot

Официальный Telegram Business-бот для автоматического сохранения:
1. **Удаленных сообщений** в личных чатах (текст, фото, видео, голосовые, стикеры, документы и кружочки).
2. **Фото и видео с ограниченным просмотром / таймером (view-once / TTL)** — достаточно просто ответить на полученное медиасообщение любым символом (например точкой `.`), и бот извлечет `file_id` через `reply_to_message` и пришлет постоянную копию в ЛС бота.

---

## 🛠 Архитектура
- Работает через официальный **Telegram Business Bot API** (`aiogram 3.x`).
- Хранит историю сообщений в локальной асинхронной базе данных SQLite (`aiosqlite`).
- Не требует авторизации по номеру телефона / сессий юзербота.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации
1. Создайте нового бота в [@BotFather](https://t.me/BotFather) и скопируйте полученный `HTTP API Token`.
2. Скопируйте `.env.example` в `.env`:
   ```bash
   copy .env.example .env
   ```
3. Откройте файл `.env` и укажите ваш токен:
   ```ini
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   OWNER_ID=0
   CACHE_DAYS=30
   ```

### 3. Подключение бота к вашему Telegram-аккаунту
1. В Telegram перейдите в **Настройки -> Telegram Business -> Чат-боты**.
2. Введите юзернейм вашего бота (например `@my_iseeall_bot`) и добавьте его.
3. Разрешите боту доступ к сообщениям и ответам.

### 4. Запуск
```bash
python bot.py
```

---

## 🎯 Как пользоваться
1. **Удаленные сообщения:** если собеседник удалит текст или медиа в вашем личном чате, бот моментально пришлет уведомление и удаленный контент вам в ЛС.
2. **Медиа с таймером / ограничением просмотра:** если вам отправили одноразовое фото или видео, сделайте ответ (Reply) на него любым символом (например `.`), и бот пришлет вам постоянный файл в ЛС.
