# 👁 iSeeAll — Telegram Business Bot

Официальный Telegram Business-бот для автоматического сохранения и экспорта переписок:
1. **Экспорт и дамп диалогов (HTML-архив):** сохранение полной истории чатов в красивом дизайне Telegram Desktop Light Theme со всеми встроенными фото, кликабельным зумом и аудиоплеером голосовых сообщений.
2. **Удаленные сообщения:** моментальный перехват и дублирование удаленных текстов, фото, видео, голосовых, кружков, документов и стикеров в ЛС владельца.
3. **Фото и видео с таймером (view-once / TTL):** достаточно ответить на полученное медиасообщение любым символом (например точкой `.`), и бот пришлет постоянную копию в ЛС бота.
4. **Скрытые команды в чате:** команды `.mute`, `.unmute` и `.dump` мгновенно и бесследно стираются из бизнес-чата, оставаясь невидимыми для собеседника.
5. **Аварийный автодамп:** при массовом удалении сообщений собеседником бот автоматически сгенерирует и пришлет архив всей переписки.

---

## 🛠 Архитектура
- Работает через официальный **Telegram Business Bot API** (`aiogram 3.x`).
- Хранит историю сообщений в локальной асинхронной базе данных SQLite (`aiosqlite`).
- Не требует авторизации по номеру телефона / сессий юзербота.
- Нулевой расход диска на дампы: архивы генерируются на лету в оперативной памяти (`BufferedInputFile`) и сразу отдаются в Telegram.

## 🚀 Быстрый старт на VPS (одна команда)

Подходит для Ubuntu/Debian. Рекомендуется зарубежный VPS — тогда Telegram API доступен напрямую, без прокси.

**Вариант 1. Одной командой (быстрее всего):**
```bash
curl -sSL https://raw.githubusercontent.com/iSeeAll-bot/iSeeAll/main/install.sh | sudo bash
```

**Вариант 2. Через git clone:**
```bash
git clone https://github.com/iSeeAll-bot/iSeeAll.git
cd iSeeAll
sudo bash install.sh
```

Установщик сам:
- поставит Python3, виртуальное окружение и все зависимости;
- скопирует проект в `/opt/iSeeAll`;
- спросит **токен бота** (из @BotFather) и **твой Telegram ID** (из @userinfobot);
- создаст `.env`, настроит systemd-сервис с автозапуском и сразу запустит бота.

После установки напиши своему боту `/start` в Telegram, затем подключи его к аккаунту:
**Профиль → Изменить → Автоматизация чатов (Бизнес)** → добавь бота и разреши доступ к сообщениям.


## 🛠 Ручная установка (если хочется своими руками)

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
1. Создайте нового бота в [@BotFather](https://t.me/BotFather) и скопируйте полученный `HTTP API Token`.
2. Скопируйте `.env.example` в `.env`:
   ```bash
   copy .env.example .env
   ```
3. Откройте файл `.env` и укажите ваш токен:
   ```ini
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
   OWNER_ID=0
   CACHE_DAYS=30
   ```

### 3. Подключение бота к вашему Telegram-аккаунту
1. В Telegram перейдите в **Настройки -> Telegram Business -> Чат-боты**.
2. Введите юзернейм вашего бота (например `@my_iseeall_bot`) и добавьте его.
3. Разрешите боту доступ к сообщениям и ответам.

### 4. Запуск
```bash
python bot.py
```

## 🎯 Как пользоваться

### 1. Выгрузка и дамп диалогов (HTML)
* **`/dump` в ЛС с ботом:** открывает интерактивное меню со списком ваших диалогов с кнопками пагинации (по 5 собеседников на страницу). Нажмите на любого человека, чтобы за секунду получить файл `.html` со всей перепиской, встроенными фото и плеером голосовых сообщений.
* **`/dump <chat_id>` в ЛС с ботом:** прямая выгрузка переписки конкретного чата по его ID.
* **`.dump` прямо в бизнес-чате:** напишите `.dump` (или `.dump 50` для последних 50 сообщений) прямо в диалоге с собеседником — сообщение команды мгновенно удалится из переписки, а готовый дамп прилетит вам в ЛС бота.
* **Аварийный дамп:** если собеседник пытается скрыть следы и массово удаляет сообщения, бот автоматически сгенерирует и пришлет полный дамп переписки вам в ЛС.

### 2. Удалённые сообщения
Если собеседник удалит текст, фото, видео, войс, кружок, документ или стикер в вашем личном чате, бот моментально пришлет уведомление и удаленный контент вам в ЛС.

### 3. Одноразовые фото и видео (View Once / TTL)
Если вам отправили фото или видео с таймером просмотра, сделайте ответ (Reply) на него любым символом (например точкой `.`), и бот извлечет файл и пришлет вам постоянную копию в ЛС.

### 4. Мут чатов (.mute / .unmute)
Напишите `.mute` прямо в диалоге, чтобы включить мгновенное автоудаление любых новых сообщений собеседника. Чтобы отключить — напишите `.unmute` (также поддерживается опечатка `.ummute`). Сообщения команд автоматически удаляются из чата.
